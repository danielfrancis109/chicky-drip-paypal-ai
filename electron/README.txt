CHICKY DRIP FOR WINDOWS (64-bit)

Extract the entire ZIP into a folder, then open Chicky Drip.exe.
Keep the executable with all the included files and folders.
Internet access is required. This app opens the published Chicky Drip website;
website updates appear after they have been published.

Email sign-in and orders use the same account as the website.
For Google or Lovable sign-in, use Chicky Drip > Open in browser;
social sign-in is not verified within the desktop app.

This is a portable app, not an installer. It is not code-signed;
Windows may display an unrecognized-app warning. Windows execution
has not been tested in the Linux packaging environment.
